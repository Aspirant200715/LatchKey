# ADR 0002: Scope and cut line

Status: accepted (2026-10-24)

## Context
Deadline and team size are unknown (D2). The project is a single-developer end-term project.

## Decision
Follow the plan's cut line: M-1 to M3, the hot-key test, four fault rows, the verifier and the write-up are mandatory. The frontend console (M3f) is added because a third person must be able to use the system. M4, the rest of M5, M6 and M6b are added in that order if time allows.

## Consequences
M6b (external side effect) is the first item cut. Anything beyond the line needs its own ADR.
